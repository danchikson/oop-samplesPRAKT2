# Система Ритейл - Імітаційний прототип

## Опис проєкту

Це імітаційний прототип об'єктно-орієнтованої системи постачання товарів у роздрібній торгівлі, розроблений мовою Java. Система демонструє базові концепції ООП: спадкування, поліморфізм, інтерфейси та взаємодію між класами.

## Архітектура

Система складається з таких основних компонентів:

### Сутності (Models)
- **SupplyOrder** - замовлення постачання з унікальним ID та статусом
- **OrderPosition** - позиція замовлення з назвою товару, кількістю та ціною
- **DeliveryService** - служба для обробки доставки

### Учасники (Participants)
- **ParticipantSupply** - абстрактний базовий клас для всіх учасників
- **Manager** - менеджер магазину (створює замовлення та оформлює повернення)
- **Supplier** - постачальник (підтверджує замовлення та виставляє накладні)
- **Logistician** - логіст (планує доставку та відстежує доставки)

### Інтерфейси
- **ISupplyPlan** - інтерфейс для планування постачання

## Вимоги

- Java Development Kit (JDK) версії 8 або вище
- Операційна система з підтримкою командного рядка (Linux, macOS, Windows)

## Компіляція

Для компіляції всіх Java файлів, перейдіть в каталог `src` та виконайте:

```bash
cd retail-project/src
javac *.java
```

## Запуск програми

Після успішної компіляції, запустіть програму командою:

```bash
java Application
```

## Вивід програми

Програма демонструє три сценарії:

1. **Сценарій 1** - Успішне замовлення з повною послідовністю дій:
   - Менеджер створює замовлення
   - Додавання позицій до замовлення
   - Підтвердження замовлення постачальником
   - Виставлення накладної
   - Планування та виконання доставки

2. **Сценарій 2** - Замовлення з поверненням:
   - Весь процес замовлення
   - Оформлення повернення менеджером

3. **Сценарій 3** - Демонстрація архітектури системи
