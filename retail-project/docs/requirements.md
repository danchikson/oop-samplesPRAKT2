# Вимоги до системи "Ритейл"

## Опис предметної області
Система призначена для автоматизації процесу постачання товарів у роздрібній торгівлі.

## Актори (Учасники постачання)
1. **Менеджер магазину**: Створює замовлення та оформлює повернення.
2. **Постачальник**: Підтверджує замовлення та виставляє накладну.
3. **Логіст**: Планує доставку та відстежує її.

## Функціональні вимоги
1. Менеджер має можливість створити замовлення, вказавши позиції товарів.
2. Постачальник отримує замовлення, підтверджує його та формує накладну.
3. Логіст отримує дані про накладну, планує доставку через службу доставки.
4. Система повинна дозволяти відстеження статусу доставки.
5. У разі проблем з товаром, Менеджер може оформити повернення.

## Сутності
- Замовлення постачання (SupplyOrder)
- Позиція замовлення (OrderPosition)
- Служба доставки (DeliveryService)
