# Швидкий старт

## Крок 1: Перейти в каталог проєкту
```bash
cd retail-project/src
```

## Крок 2: Скомпілювати програму
```bash
javac *.java
```

Цей comando скомпілює всі 9 Java файлів:
- Application.java (головний клас)
- SupplyOrder.java (замовлення)
- OrderPosition.java (позиція замовлення)
- DeliveryService.java (служба доставки)
- ParticipantSupply.java (абстрактний клас учасника)
- Manager.java (менеджер)
- Supplier.java (постачальник)
- Logistician.java (логіст)
- ISupplyPlan.java (інтерфейс)

## Крок 3: Запустити програму
```bash
java Application
```

## Очікуваний результат
Програма покаже імітацію роботи системи постачання товарів:
- Сценарій 1: Успішне замовлення з доставкою
- Сценарій 2: Замовлення з поверненням
- Сценарій 3: Демонстрація архітектури системи

## Потребуються
- Java Development Kit (JDK) 8+
- Термінал/консоль

## Основні концепції, продемонстровані в проекті
✓ Спадкування (extends)
✓ Абстрактні класи
✓ Інтерфейси (implements)
✓ Поліморфізм
✓ Інкапсуляція
✓ Композиція об'єктів
✓ Collections (ArrayList)
