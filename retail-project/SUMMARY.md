   - Більш наочні ніж PlantUML
   - Легше інтегруються з GitHub
   - Детальніші

### Розбіжності та проблеми

1. **Class Diagram - пропущені деталі**
   - ⚠️ Атрибут `deliveryService` в Logistician не показаний у PlantUML
   - ⚠️ Гетери в SupplyOrder та OrderPosition не показані у PlantUML
   - **Рекомендація:** Оновити class.puml

2. **Sequence Diagram - спрощена версія**
   - ⚠️ Методи `addPosition()` та `trackDelivery()` не показані у PlantUML
   - ⚠️ Метод `executePlan()` не показаний явно у PlantUML
   - ⚠️ Другий сценарій з поверненням не показаний у PlantUML
   - **Рекомендація:** Додати в sequence.puml

3. **Назви статусів**
   - ⚠️ PlantUML показує "Shipping", Java використовує "Invoiced" → "Delivered"
   - **Рекомендація:** Уточнити номенклатуру

4. **Документація потребує уточнень**
   - ⚠️ Деякі аспекти архітектури не задокументовані
   - **Рекомендація:** Додати коментарі в код
